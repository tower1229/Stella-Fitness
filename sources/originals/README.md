# Original Source Artifacts

本目录保存 Stella Fitness 首个训练计划的原始 Office 来源文件，作为 `knowledge/` 结构化内容的可追溯原件。

当前收录：

- `zhuoshu-hypertrophy-course.docx` — 《卓叔增重 · 结构化增肌增重教程》原始 DOCX；
- `zhuoshu-workout-log.xlsx` — 原课程三阶段训练情况记录表原始 XLSX。

## 治理规则

1. 本目录中的 Office 文件作为原始来源归档，不在仓库内改写其内容；
2. `knowledge/` 中的 Markdown / ProgramSpec 是派生、可审阅、可版本化的结构化层；
3. 用户已于 2026-08-08 明确确认允许将这两份原始 Office 文件提交到本公开 GitHub 仓库；
4. 卓叔计划将作为 v1 `Built-in Program`，但这些原件只作公开源码仓库审计归档，不进入正式发行包；
5. 如原件内容与派生文档发生冲突，应回溯原件并记录 reconciliation，而不是静默修改来源事实。

## 权利边界

本目录中的原始 DOCX/XLSX 不适用仓库根目录的 Apache-2.0 软件许可。当前确认仅覆盖公开仓库收录；派生、修改、署名和安装包渠道的再分发仍须单独取得并保存可核验授权。
