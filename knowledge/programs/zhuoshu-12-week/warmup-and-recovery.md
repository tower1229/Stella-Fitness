# 统一热身与放松

> 以下内容来自原教程对所有训练日通用的热身与练后放松安排。

这些内容是可复用选项，不是强制完成清单。热身是否进行、选择哪些动作以及是否使用弹力带，均由用户自由裁量。

## 练前热身

| 动作 | 原教程说明 |
|---|---|
| 高抬腿 | 激活下肢，提升心率 |
| 伟大拉伸 | 全身动态拉伸，活动髋、肩、胸椎 |
| 侧蹲 | 激活髋内收肌，活动髋关节 |
| 弹力带绕肩 | 激活肩袖肌群，预热肩关节 |

## 练后放松

| 动作 | 目标区域 |
|---|---|
| 拉伸胸大肌 | 胸部肌群 |
| 拉伸髂腰肌 | 髋部屈肌 |
| 放松髂胫束 | 大腿外侧筋膜，可用泡沫轴 |
| 放松背阔肌 | 背部肌群 |

## ProgramSpec 表达原则

热身和放松属于所有训练日共享的 `session_defaults`，不应在每一个训练日重复硬编码。热身必须显式标记为 `required: false` 与 `selection: user_discretion`；列出的动作是 options，不是必须全部完成的 sequence。

原教程没有为上述热身动作给出统一的次数、时长或组数，因此 Program Engine 不得自行生成精确数值。
