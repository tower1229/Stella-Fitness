# Stella Fitness

> An OpenClaw plugin for AI-powered hypertrophy supervision.

Stella Fitness is not an AI personal trainer that replaces a training plan. It is an objective long-term supervisor that observes execution data, analyzes trends, and provides evidence-based adjustment suggestions.

## Vision

Human executes. Agent observes. Evidence decides.
