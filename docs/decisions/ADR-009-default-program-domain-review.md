# ADR-009 — Default Program Requires Action-Bearing Domain Review

**Status:** Accepted for v1 requirements  
**Date:** 2026-08-08

来源忠实只证明 ProgramSpec 正确表达了原教程，不构成专业背书。卓叔 12 周计划在成为 v1 `Default Program` 前，必须由独立 Domain Reviewer 审核所有会驱动用户行为的训练处方，包括动作选择、频率与训练量、负重递进、12RM 测试、恢复周及引体辅助规则；教程中的饮食内容只作为来源示例，不进入自动饮食 Supervision Policy，营养 Policy 另行审核。背景叙述与文案润色不在本次专业审核范围内。若无法获得合格签署，该计划只能作为开发与验收使用的 `Default Program Candidate` 和用户可导入的来源样例，不能标记为已专业审核的默认计划，也不能驱动自动数值调整。
